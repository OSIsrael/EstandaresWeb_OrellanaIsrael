# Ficha Personalizada - Práctica de Estándares Web

| Temática | Campos especiales del formulario | Breakpoint principal | Restricción especial |
| :--- | :--- | :--- | :--- |
| Clínica veterinaria | Teléfono ecuatoriano validado con `pattern` | 600 px | Layout principal con `grid-template-areas` que cambia de orden en móvil |

## Detalle de Requisitos de la Ficha
* **Temática:** Clínica veterinaria
* **Campo especial del formulario:** Validación estricta de teléfono ecuatoriano mediante el atributo `pattern` (fijos y celulares).
* **Breakpoint principal:** 600 px (punto de quiebre para el diseño en pantallas medianas/escritorio).
* **Restricción especial:** Layout principal estructurado mediante `grid-template-areas` que reorganiza el orden visual de los elementos entre dispositivos móviles y pantallas de escritorio.
